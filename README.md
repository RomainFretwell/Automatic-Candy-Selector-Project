# Automatic Candy Selector

Projet IA IN450/451 : reconnaître des bonbons sur des photos. Deux parties rendues séparément :
- [`classification/`](classification/README.md) : une photo = un bonbon -> type + couleur (ResNet-50, PyTorch)
- [`detection/`](detection/README.md) : une photo = plusieurs bonbons -> position + classe de chacun (YOLO)

L'environnement Python `.venv/` (pas dans git) est partagé par les deux parties.
